# 몽글몽글 벽돌깨기

귀여운 구름 나라를 배경으로 만든, 설치 없이 즐길 수 있는 벽돌깨기 게임입니다.

## 실행 방법

`index.html`을 브라우저에서 열면 바로 플레이할 수 있습니다. GitHub Pages에 게시하면 별도 설치 없이 웹에서도 실행됩니다.

## GitHub Pages 배포 방법

1. GitHub에 새 공개 저장소 생성
2. 이 폴더의 `index.html`과 필요한 정적 파일을 업로드
3. GitHub 저장소에서 `Settings` → `Pages` 선택
4. `Deploy from a branch` 선택 → `main` 브랜치, 폴더 `/ (root)` 선택
5. 저장 후 GitHub Pages URL이 생성됨

예시 주소:
`https://<사용자이름>.github.io/<저장소이름>/`

## 조작 방법

- 마우스 또는 손가락으로 좌우 이동
- 키보드 `←` / `→` 또는 `A` / `D`로 이동
- 화면 클릭·터치 또는 `스페이스`로 별공 출발
- `스페이스` 또는 `P`로 일시정지
- 별 아이템을 받으면 패들이 커집니다
- 오른쪽 위 음표 버튼으로 효과음을 켜거나 끌 수 있습니다
